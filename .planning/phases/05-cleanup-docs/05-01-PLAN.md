```markdown
# AWS VPN Client

A native macOS menu bar app for AWS Client VPN. Connects silently in the background --
click a config in the menu bar, authenticate via SAML, walk away.

Supports multiple simultaneous VPN connections, each with independent state tracking.
Includes a companion `aws-connect` CLI for terminal workflows.

## Prerequisites

### Patched OpenVPN

AWS Client VPN requires a patched build of OpenVPN with increased buffer sizes for SAML
authentication. This repo includes a Homebrew formula that builds OpenVPN 2.6.19 with the
required patches.

> **Note:** This will conflict with an existing OpenVPN installation.

```sh
brew tap awsvpn/aws-vpn-client /path/to/this/repo
brew install awsvpn/aws-vpn-client/openvpn-aws
```

Replace `/path/to/this/repo` with the absolute path to your clone of this repository.

Verify the installation:

```sh
openvpn --version | head -1
# Should show: OpenVPN 2.6.19 ...
```

### Sudoers Entry

OpenVPN requires root privileges to create tunnel interfaces. Add a NOPASSWD entry so the
app can launch `sudo openvpn` without a password prompt:

```sh
echo "$(whoami) ALL=(ALL) NOPASSWD: /usr/local/bin/openvpn" | sudo tee /etc/sudoers.d/openvpn
```

## Building the App

Build the Release configuration with xcodebuild:

```sh
xcodebuild -project AWSVPNClient.xcodeproj -scheme AWSVPNClient -configuration Release build
```

The built app bundle lands in DerivedData. To find it:

```sh
xcodebuild -project AWSVPNClient.xcodeproj -scheme AWSVPNClient -configuration Release build -showBuildSettings | grep -m1 BUILT_PRODUCTS_DIR
```

Optionally copy the app to a permanent location:

```sh
cp -R "$(xcodebuild -project AWSVPNClient.xcodeproj -scheme AWSVPNClient -configuration Release build -showBuildSettings 2>/dev/null | grep -m1 BUILT_PRODUCTS_DIR | awk '{print $3}')/AWSVPNClient.app" ~/Applications/
```

## Installing the CLI

The `aws-connect` CLI binary is embedded inside the app bundle. Symlink it into your PATH
so it survives app rebuilds (per D-06):

```sh
ln -sf ~/Applications/AWSVPNClient.app/Contents/MacOS/aws-connect /usr/local/bin/aws-connect
```

If you did not copy the app to `~/Applications/`, adjust the path to wherever your
`AWSVPNClient.app` lives.

## Adding Configs

Copy your AWS VPN `.conf` files into the app's config directory:

```sh
mkdir -p ~/Library/Application\ Support/AWSVPNClient/configs
cp your-vpn.conf ~/Library/Application\ Support/AWSVPNClient/configs/
```

You can also add configs from the menu bar: click the menu bar icon and select
**Add Config...** to pick a `.conf` file via a file dialog.

## Usage

### Menu Bar App

Launch `AWSVPNClient.app`. A lock icon appears in the menu bar.

- Click a config name to connect (opens browser for SAML authentication)
- Click a connected config to disconnect
- **Add Config...** adds a new `.conf` file
- **Remove Config** submenu removes a config
- **View Logs** submenu opens per-connection logs in Console.app
- Lock icon shows `lock.fill` when any connection is active

### CLI

The app must be running for the CLI to work. It communicates over a Unix socket.

```sh
# Connect to a VPN config
aws-connect staging

# Disconnect
aws-connect --disconnect staging

# Show status of all configs
aws-connect status
```

If the app is not running, the CLI prints:
`Start the AWSVPNClient menu bar app first`

## Architecture

```
AWSVPNClient.app/
  Contents/
    MacOS/
      AWSVPNClient     # Menu bar app
      aws-connect      # Companion CLI
    Frameworks/
      VPNCore.framework # Shared types and VPN management logic
```

- **AWSVPNClient** -- SwiftUI menu bar app (MenuBarExtra, macOS 14+)
- **VPNCore** -- Framework with VPNManager, connection state machine, config parsing, IPC types
- **aws-connect** -- CLI that talks to the running app over a Unix domain socket at
  `~/Library/Application Support/AWSVPNClient/daemon.sock`
```
