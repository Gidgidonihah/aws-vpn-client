**Verification checklist:**

**1. Empty state (no configs):**
- Click the lock icon in the menu bar
- Verify: Shows "No configs — use Add Config..." as grayed text
- Verify: "Add Config...", "Remove Config", "View Logs", dividers, and "Quit AWSVPNClient" are present

**2. Add Config flow:**
- Click "Add Config..."
- Verify: NSOpenPanel appears IN FRONT of other windows (not behind)
- Verify: Panel filters to .conf files
- Select a valid .conf file
- Verify: Config name now appears in the menu list

**3. Config row layout:**
- Verify: Config name is left-aligned
- Verify: No state indicator shown for disconnected config (name only)

**4. Connect flow (if openvpn + SAML infra available):**
- Click a config name to initiate connection
- Verify: State shows "⏳ authenticating" right-aligned
- Verify: Other disconnected configs become grayed/disabled
- After SAML completes: Verify state shows "● Connected" in green
- Verify: Menu bar icon changes to lock.fill (filled lock)

**5. Disconnect flow:**
- Click a connected config
- Verify: State transitions to disconnected, icon returns to lock.open

**6. Remove Config:**
- Open "Remove Config" submenu
- If a config is connected/authenticating: Verify it is grayed/disabled in the submenu
- Select a disconnected config to remove
- Verify: Config disappears from menu immediately
- Verify: File moved to Trash (check Finder Trash)

**7. View Logs:**
- Open "View Logs" submenu
- Select a config
- Verify: Console.app opens showing the log file

**8. Quit:**
- Click "Quit AWSVPNClient"
- Verify: App terminates cleanly

**Note:** Steps 4-5 require a working VPN config with openvpn installed. If not available, verify steps 1-3, 6-8 and confirm the connect button triggers the expected flow (browser opens for SAML).
