AWSVPNClient.app/Contents/MacOS/ during builds. The rpath architecture is proven correct

as a standalone product at Build/Products/Debug/aws-connect instead of inside the app bundle.

with both binaries, so the rpath resolves without manual file placement.

  <action>
Edit project.yml to add the aws-connect target as a dependency of the AWSVPNClient target,
configured to copy the CLI binary into the app's executables directory (Contents/MacOS/).

In the AWSVPNClient target's `dependencies` list, add a second entry after the existing
VPNCore dependency:

```yaml
  AWSVPNClient:
    dependencies:
      - target: VPNCore
        embed: true
        codeSign: false
      - target: aws-connect
        embed: true
        codeSign: false
        copy:
          destination: executables
```

This tells XcodeGen to generate a Copy Files build phase that copies the aws-connect
product into `Contents/MacOS/` of the AWSVPNClient app bundle.

After editing project.yml, regenerate the Xcode project:
```bash
cd /Users/jason/Sites/termly/sandbox/aws-vpn-client && xcodegen generate
```

Then verify the build produces the CLI inside the bundle:
```bash
xcodebuild clean build -project AWSVPNClient.xcodeproj -scheme AWSVPNClient -configuration Debug 2>&1 | tail -5
```

Then confirm aws-connect exists inside the app bundle:
```bash
BUILT=$(find ~/Library/Developer/Xcode/DerivedData/AWSVPNClient-* -path '*/Build/Products/Debug/AWSVPNClient.app/Contents/MacOS/aws-connect' -type f 2>/dev/null | head -1)
if [ -n "$BUILT" ]; then
  echo "PASS: aws-connect found at $BUILT"
  # Verify rpath resolves
  DYLD_PRINT_LIBRARIES=1 "$BUILT" 2>&1 | head -20
else
  echo "FAIL: aws-connect not found in app bundle"
fi
```

If the `embed: true` + `copy.destination: executables` approach does not work for tool
targets (XcodeGen may not support embedding tool targets this way), use a postBuildScript
fallback:

```yaml
  AWSVPNClient:
    postBuildScripts:
      - name: "Copy aws-connect into app bundle"
        script: |
          cp "${BUILT_PRODUCTS_DIR}/aws-connect" "${BUILT_PRODUCTS_DIR}/AWSVPNClient.app/Contents/MacOS/aws-connect"
        inputFiles:
          - "$(BUILT_PRODUCTS_DIR)/aws-connect"
        outputFiles:
          - "$(BUILT_PRODUCTS_DIR)/AWSVPNClient.app/Contents/MacOS/aws-connect"
```

Also add aws-connect as a dependency (without embed) so it builds before the app:
```yaml
    dependencies:
      - target: VPNCore
        embed: true
        codeSign: false
      - target: aws-connect
        embed: false
```
