## Decisions Made
- **Dynamic framework rpath confirmed** — spike passed; SPM pivot not needed. The three-target architecture is the path forward for all subsequent phases.
- **VPNCore needs its own Info.plist** — XcodeGen doesn't auto-generate `Info.plist` for framework targets unless `info:` block is specified. Without it, codesign rejects the embedded framework as "bundle format unrecognized". Fix was adding `info.path: VPNCore/VPNCore-Info.plist` to project.yml.
- **Embed Without Signing** — `codeSign: false` in XcodeGen dep spec uses "Embed Without Signing" mode. This avoids the double-signing pitfall documented in RESEARCH.md Pitfall E.
